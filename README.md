# 🎮 Gaming Review Website (Blazor)

A personal gaming review and content website built using **Blazor**, designed as an exploration of modern .NET-based web development and component-driven UI architecture.

This project serves both as a **functional review platform** and a **front-end architecture experiment using Blazor WebAssembly / Server concepts**.

---

## 🧭 Overview

This project was built to explore:

- Modern web UI development using **Blazor**
- Component-based architecture in C#
- Building SPA-like experiences without heavy JavaScript frameworks
- Static hosting using GitHub Pages (`github.io`)
- Structuring a lightweight content-driven web application

The site functions as a **gaming review hub**, where content is organized and rendered dynamically through reusable Blazor components.

---

## 🎯 Purpose of the Project

The main goals behind this project were:

- Learn and apply **Blazor (C# web UI framework)**
- Build a real-world content site using .NET instead of JS frameworks
- Experiment with SPA-like navigation and component reuse
- Host a fully functional website on **GitHub Pages**
- Create a scalable structure for future expansion (reviews, ratings, tags, etc.)

---

## 🧱 Architecture

The site is structured around Blazor’s component model:

### 🧩 Component-Based UI
- Pages are built from reusable Razor components
- Separation of layout, content, and logic
- Consistent UI structure across pages

### 📄 Content System
- Reviews are represented as structured data
- Designed to be easily extendable (new games / categories)
- Supports future integration of filtering, tagging, and rating systems

### 🌐 Front-End Application Model
- Single Page Application (SPA) behavior via Blazor routing
- No full page reloads between navigation
- Smooth transitions between sections
